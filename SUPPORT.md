# Support

PyTransformer is maintained as a public command-line utility suite.

## Questions And Bugs

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Installation problems.
- Feature requests.

Please include:

- The exact `pyt-*` command or Python module.
- Python version and operating system.
- Installed optional dependency group, such as `.[pdf]` or `.[jpeg]`.
- A minimal command that reproduces the issue.
- Terminal output with private paths, metadata, and file contents removed.

## Security

Do not open public issues for suspected security problems or private-data exposure. Follow [SECURITY.md](SECURITY.md) instead.

## Private Files

Follow the [privacy guidance for fixtures and diagnostics](docs/privacy.md#development-fixtures-and-diagnostics) before attaching source files or logs. Prefer a small synthetic fixture.
